# Agent guidelines

## Repository guidance

- Follow [CODING_STANDARDS.md](CODING_STANDARDS.md) for coding conventions.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) for change workflows, verification, schema changes and journey tests.
- Use [CONTEXT.md](CONTEXT.md) for service terminology.
- Treat code, tests and configuration as the source of truth for implemented behaviour. Link to them rather than duplicating logic; retain domain meaning, decision rationale, external contracts and operational guidance that code alone cannot provide.
